# Changelog

## 1.0.0

First public release.

- Pattern generator with presets and trending patterns. The length range stretches the pattern to fit.
- Brandable mode: syllable names, or real English words.
- Filters: start, end, contains, excluded characters, blocklist with leetspeak, no repeats, no consecutive digits, reset, and an active-filter count.
- Clear explanations when inputs can never match, naming the platform that forbids them (for example a name starting with ".").
- Platform rules for 12 platforms. Discord, Instagram, TikTok, Telegram, X and YouTube were checked against published rules. The rest are marked unverified.
- Availability checks: Taken, Likely available, Unknown, Can't check here, Invalid. 24-hour cache, rate-limit backoff, and Verify in browser.
- Name Score (five factors) with a tooltip, and sorting by score.
- Favorites with notes, import and export (JSON and CSV), and copy all.
- Used marks with platform logos, and a similarity warning.
- Reserved names with a reminders manager (Reserved, Registered, Dropped).
- History of the last 100 batches, with restore.
- Arabic and English with right-to-left layout, Dark and Light themes.
- Editable keyboard shortcuts, and a `?` cheat sheet.
- Pronunciation preview when a speech engine is available.
- Results: lightweight cards, a 300-name limit per session, and a confirmation before large availability checks.
